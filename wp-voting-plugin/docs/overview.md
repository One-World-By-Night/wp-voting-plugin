# WP Voting Plugin Overview

The WP Voting Plugin runs OWbN's council votes on council.owbn.net: proposals, elections, disciplinary votes and consent agenda items, from the ballot to the result.

## What it does

- **Votes.** Seven ways to vote, from a single choice to ranked elections for several seats, see [Voting Types](help/voting-types.md).
- **Schedules.** A vote opens and closes on its own dates, and its result is counted as soon as it closes.
- **Who can see and who can vote.** Each vote names the roles that can see it and the roles that can vote on it, such as every chronicle's CM.
- **Results.** Counts, rounds, who voted and who didn't, and comments, see [Vote Results](help/results.md).
- **Email.** Notices when a vote opens, a reminder the day before it closes, and the result when it closes.
- **Vote history.** Other OWbN sites show how each chronicle and coordinator voted, through OWBN Core.

## Who does what

- **CMs, coordinators and the others a vote names** cast ballots, see [Voting](help/casting-a-ballot.md).
- **Site admins and the Web team** create and run votes, see [Creating and Editing a Vote](help/vote-editor.md).

## Getting help on a screen

Every WP Voting screen in wp-admin has a **?** next to its title that opens its help page right there, and every page is also here on support.owbn.net. **WP Voting** → **Guide** in wp-admin explains the voting methods and the permission rules in more depth.
